Capacious

Full-stack manuscript review & publishing management

Python FastAPI SQLAlchemy TypeScript Next.js PostgreSQL Docker

Capacious is a full-stack publishing management platform built for academic journals. It handles the complete editorial lifecycle — from initial manuscript submission through double-blind peer review, author revisions, copy editing, and final publication.

The system supports five distinct roles (author, reviewer, copy editor, managing editor, and admin), each with tailored views and permissions. A role-aware dashboard surfaces only the submissions and actions relevant to the current user, with an action ribbon system that flags when input is needed.

Built with a FastAPI + SQLAlchemy async backend, a Next.js 15 frontend with TanStack Query, and PostgreSQL for persistence. The whole stack runs in Docker Compose for reproducible local development.

Tech Stack

Backend: Python, FastAPI, SQLAlchemy 2.0, Alembic, PostgreSQL

Frontend: TypeScript, Next.js 15, React 19, Tailwind CSS, TanStack Query

Infra: Docker, Docker Compose, AWS S3

Testing: pytest with transactional isolation

Features

Dashboard

Role-aware landing page that filters submissions by the user's role and status. An action ribbon system highlights submissions that need immediate attention — covering 16+ distinct action item types across all roles.

Submission Management

Authors submit manuscripts with title, abstract, keywords, and file attachments. Submissions are tracked through each stage of the lifecycle: desk review, peer review, revisions, copy editing, and publication. File versioning keeps a full history of uploaded manuscripts.

Screenshot coming soon

Double-Blind Peer Review

Editors assign reviewers per submission and round. Author identities are hidden from reviewers and vice versa. Reviewers submit recommendations (Accept through Reject), confidential comments to the editor, and comments to the author. Editors can batch-release reviews to authors at the end of each round, and optionally edit reviewer comments before release.

Screenshot coming soon

Copy Editing Workflow

Copy editors are assigned per submission and upload edited manuscripts with notes. Editors review the work and release it to authors, who can respond to suggestions. Supports multiple copy edit rounds and a bio confirmation flow.

Screenshot coming soon

File Management & Viewer

Supports PDF, DOCX, images, audio, and video uploads. An integrated file viewer with navigation toolbar lets users review manuscripts directly in the browser without downloading. Files are versioned and stored via AWS S3.

Screenshot coming soon

Activity Log

A full audit trail of every action taken on a submission, grouped by editorial stage. Tracks status changes, assignments, reviewer comments, file uploads, and decisions — giving editors a complete history at a glance.

Screenshot coming soon

Documentation

Integrated MDX documentation with full-text search, covering user guides for each role. The search index is pre-built at dev and build time using MiniSearch.
