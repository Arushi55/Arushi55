Northeastern Science Magazine

Full-stack platform for a student-run science publication

TypeScript Next.js React Node.js Express MongoDB Mongoose Tailwind CSS

A full-stack web platform for Northeastern's student-run science magazine, covering the public reading experience and the internal editorial workflow. The frontend is a Next.js 14 app with a purpose-built component design system; the backend is an Express REST API managing articles, users, photos, and multi-stage publishing pipelines.

Articles move through parallel writing, design, and photography review tracks before publication. Internal tools handle submission, approval queues, and team management — all gated behind role-based access control for authors, editors, photographers, designers, and admins.

The backend uses a strict accessor pattern that separates database queries from business logic, with Zod schema validation at every API boundary and JWT authentication stored in HTTP cookies.

Tech Stack

Frontend: TypeScript, Next.js 14, React 18, Tailwind CSS, Radix UI, Framer Motion

Backend: Node.js, Express 5, MongoDB, Mongoose, Zod, JWT, bcryptjs

Tooling: Storybook, Jest, Supertest, Docker

Email: Resend API

Features

Public Article Platform

Server-rendered article pages, magazine issue browsing, and a homepage with featured and recent content. Articles carry rich structured data — body paragraphs, pull quotes, embedded images, and source links — rendered from a flexible content schema.

Design System

A two-tier component library built from scratch: 25+ atomic primitive components (Button, Card, Input, Badge, Avatar, Dialog) compose into higher-level compounds (Header, Footer, MediaCarousel). All components are documented and previewed in Storybook, with Tailwind Variants driving flexible configuration.

Screenshot coming soon

Editorial Workflow & Internal Tools

Internal pages for article submission and multi-stage approval. Each article progresses through separate writing, design, and photography status tracks, with editors managing approvals at each stage. Role-based access control limits what each team member (author, editor, photographer, designer, admin) can view and act on.

Screenshot coming soon

Article Search

Full-text search powered by MongoDB Atlas Search with fuzzy matching across article titles and body content. The frontend exposes filtered discovery by category and text query with pagination, wired to a structured backend search endpoint.

Screenshot coming soon

Backend API & Authentication

An Express 5 REST API organized around a strict accessor pattern — database queries, business logic, and HTTP routing stay in separate layers. Zod validates every request at the API boundary. JWT tokens are issued on login and transmitted via HTTP cookies, with role-aware middleware guarding protected routes.
