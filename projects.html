Capacious

Python FastAPI SQLAlchemy TypeScript Next.js PostgreSQL Docker

A full-stack manuscript review and publishing management system for academic journals. Capacious handles the entire editorial lifecycle — from initial submission through double-blind peer review, author revisions, copy editing, and final publication — with role-based access for authors, reviewers, copy editors, and managing editors.

Built with a FastAPI + SQLAlchemy async backend, a Next.js 15 frontend, and PostgreSQL for persistence. Features include multi-round review workflows, editor-controlled review release, file versioning, a full activity audit trail, and integrated MDX documentation with full-text search.

Full-stack web platform for a student-run science publication. A Next.js frontend with a custom design system and internal editorial tools, backed by an Express REST API managing articles, users, and multi-stage publishing workflows across writing, design, and photography.

Crowd Navigation

Python PyTorch Gymnasium Pygame

A reinforcement learning system for training autonomous agents to navigate through crowded environments with pedestrians. Implements Deep Q-Networks with Prioritized Experience Replay, Double DQN, and Dueling DQN, alongside a Social Force Model for realistic pedestrian dynamics and a ray-casting sensor for spatial awareness.
